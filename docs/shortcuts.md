# Shortcuts

The short-keys dialog in the sidebar lists these in-app as well.

| Shortcut | Action |
| --- | --- |
| Ctrl-Enter | Execute the operation at the caret |
| Shift-Ctrl-P | Prettify editors |
| Shift-Ctrl-M | Merge fragments into the operation |
| Shift-Ctrl-C | Copy the query |
| Shift-Ctrl-R | Re-fetch the schema |
| Ctrl-Alt-K | Open documentation search |
| Ctrl-, | Settings |
| Ctrl-F | Find in editor (Monaco) |
| F1 | Command palette (Monaco, editor focused) |

The editors are Monaco, so the full VS Code editing keymap applies — multi-cursor, comment toggling, folding, find and replace.
