# BlazorQL.Bundled

An in-browser GraphQL IDE for any ASP.NET Core app, in one assembly.

```csharp
app.MapBlazorQL();
```

No Blazor SDK, no static files to deploy, and no package dependencies: the whole WebAssembly
application - runtime, IDE and editor - is embedded in the dll and served pre-compressed.

See https://github.com/SimonCropp/BlazorQL for documentation.
